# Code snippets

One file per language, `<id>.txt`. Each snippet starts with a `%% <syntax>`
header line naming its highlighter syntax, followed by 5 to 20 lines of ASCII
code: no tabs, no trailing spaces, at most 80 columns, indented with 4 spaces
(2 in `html-css.txt`). `tests/code.rs` enforces these rules.

Every snippet is original work written for PlexusTyping, not copied from any
project, and is licensed under `MIT OR Apache-2.0`, like the rest of the
crate.
